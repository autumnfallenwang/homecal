Ops notes:
  - api: single replica + Recreate strategy. The reminder scheduler is a setInterval
    singleton inside the API process; two replicas would double-fire email + APNs
    reminders.
  - db: single-replica StatefulSet with a ReadWriteOnce PVC ({{ .Values.db.persistence.size }} local-path).
    Backups today have the same parity as the legacy docker volume (none) — revisit
    when it bites.
  - llmgw: reached via in-cluster Service DNS at LLM_GATEWAY_URL=http://llmgw.llmgw.
    No more host-network workaround.
  - Real secrets (BETTER_AUTH_SECRET, EMAIL_PASSWORD, APNS_PRIVATE_KEY, POSTGRES_PASSWORD)
    live in the homecal-secrets Secret, created out-of-band (NOT committed). Swap to
    Sealed Secrets later as a no-downtime env-source change.
  - Schema migrations run via a Helm pre-install/pre-upgrade Job using drizzle-kit
    migrate against the SQL files in apps/api/drizzle/.
